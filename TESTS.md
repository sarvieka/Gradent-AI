# Gradent AI — Test Cases & Outputs

This folder contains student answer scripts and the corresponding outputs
generated by Gradent AI using the same question paper and marking rubric.

## Test Cases

| Test Case | Purpose | Expected Behaviour |
|---|---|---|
| 01 — Fully Correct | Test full-credit grading | Correct criteria receive full marks; no incorrect-answer annotations |
| 02 — Partially Correct | Test partial scoring | Partial marks with relevant feedback and annotations |
| 03 — Incorrect | Test incorrect-answer detection | Incorrect criteria receive appropriate marks and annotations |
| 04 — Blank | Test blank-answer handling | No hallucinated grading or fabricated evidence |
| 05 — Handwritten | Test handwritten answer handling | Gemini Vision extracts/understands the answer and grading proceeds normally |

## What is being tested

- Criterion-level grading against the marking rubric
- Deterministic score calculation and validation
- Evidence-based evaluation
- Incorrect/partially-correct annotations
- Typed PDF extraction
- Handwritten answer understanding
- Blank-answer detection
- Persistence of grading results and annotations
- Annotated PDF export
